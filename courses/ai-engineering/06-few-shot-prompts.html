In one line

A few-shot prompt shows the model some solved examples first, so it learns your labels and your rules from them.

What you will learn

  • Why examples help when your labels have a special meaning
  • How to build a prompt from system, human and ai messages with from_messages()
  • How each pair of messages acts as one example, one "shot"
  • How to select good examples, and where few-shot still fails

Read chapter 5 first. This chapter builds on the zero-shot classifier and its chain. Chapter 4 explains message roles.

The idea

In chapter 5, the model sorted text with an instruction only. This works when the labels are common, for example POSITIVE and NEGATIVE. Your own labels are different. A label such as CONTEXT_LOSS or PURPOSE_CONCERN has a meaning that only your team knows exactly.

A few-shot prompt adds solved examples to the prompt. Each example is one input and its correct label. The model sees the pattern and continues it for the new input. "Few-shot" means a few examples, often three to ten.

In a chat model, the best way to show an example is a fake short conversation. A human message holds the example input, and an ai message holds the correct answer. To the model, it looks as if it already answered these questions correctly. Then the real question comes as the last human message.

Real-life analogy

A new member of a security team must sort incident reports. The team lead does not give a long definition of each category. Instead, the lead shows five old reports with the category already written on them. After these examples, the new member sorts the next report in the same way. The examples teach the rules faster than a definition.

What we build in this chapter

You build two classifiers with the same few-shot pattern. The first one sorts failures of applications that use language models. The second one sorts privacy risks in mobile apps. Both use labels that a model does not know from general text.

Step 5Write the few-shot prompt

This is the most important step. The prompt is a list of messages.

    # Few-shot prompt with examples of common LLM failures
    llm_failure_analysis_prompt = ChatPromptTemplate.from_messages(
        [
            # "system", "human", and "ai" are predefined message roles.
            (
                "system",
                """You are an experienced AI engineer who analyses failures
                    in applications powered by large language models.

                    Classify each observation using exactly one label:

                    HALLUCINATION
                    PROMPT_INJECTION
                    FORMAT_VIOLATION
                    CONTEXT_LOSS

                    Respond with only the classification label.""",
            ),

            # Few-shot Example 1: Hallucination
            ("human", """The model provided the title and DOI of a research paper, but the paper does not exist."""), # "human" provides the example input.
            ("ai", "HALLUCINATION"), # "ai" provides the expected response for the example.

            # Few-shot Example 2: Prompt injection
            ("human", """A document told the model to ignore its original instructions, and the model followed the document's command."""),
            ("ai", "PROMPT_INJECTION"),

            # Few-shot Example 3: Format violation
            ("human", """The model was instructed to return valid JSON, but it returned a normal paragraph instead."""),
            ("ai", "FORMAT_VIOLATION"),

            # Few-shot Example 4: Context loss
            ("human", """The user specified Python at the beginning of the conversation, but the model later generated Java code."""),
            ("ai", "CONTEXT_LOSS"),

            # Few-shot Example 5: Hallucination
            ("human", """The model described a software library function that is not present in the official documentation."""),
            ("ai", "HALLUCINATION"),

            # Actual query supplied during invocation
            ("human", "{query}"),
        ]
    )
  • ChatPromptTemplate.from_messages([...]) builds a template from a list of messages. Chapter 5 used from_template(), which makes only one human message.
  • Each message is a pair in brackets, a tuple, with the role first and the text second. The roles are "system", "human" and "ai". LangChain turns each tuple into a message object.
  • The system message. It gives the role, the four allowed labels and the output rule "Respond with only the classification label."
  • The examples. Each ("human", ...) and ("ai", ...) pair is one shot. There are five shots. HALLUCINATION has two examples, a paper that does not exist and a library function that does not exist. Two examples help the model see what the cases have in common.
  • The real question. The last message is ("human", "{query}"). The placeholder {query} gets the new observation at each call.

Step 6Join the parts into a chain

    # The Chain
    chain = llm_failure_analysis_prompt | llm | parser

The chain has the same three parts as in chapter 5, the prompt, the model and the parser.

Step 7Add the data and run the chain for each observation

    # New LLM application observations
    sample_observations = [
        "The application requested a CSV row, but the model returned a Markdown table.",
        "The model recommended an API parameter that does not exist in the installed package.",
        "The model generated a quotation and attributed it to a person who never said it.",
        "The user requested short answers earlier, but the model started producing long explanations later.",
        "Text retrieved from a website instructed the model to reveal its system prompt, and the model attempted to comply.",
    ]

    # Invoke the chain for each observation
    for observation in sample_observations:
        result = chain.invoke({"query": observation})

        print(f"\nObservation: {observation}")
        print(f"Failure Type: {result.strip()}")
  • The five observations are new. None of them appears in the examples, so the model must apply the pattern, not copy an answer.
  • chain.invoke({"query": observation}) fills {query} and runs the chain. The key matches the placeholder.
  • result.strip() removes spaces around the label.

"""
Title: Few Shot Prompting (Google Generative AI)
uv run python src/05_few_shot_google.py
"""

from dotenv import load_dotenv
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser


def main():
    load_dotenv()

    # Initialize the model
    llm = ChatGoogleGenerativeAI(
        model="gemini-3.1-flash-lite",
        temperature=0,
    )

    # Parser to extract the text from the model response
    parser = StrOutputParser()

    print("=" * 80)
    print("FEW-SHOT LLM FAILURE CLASSIFICATION")
    print("=" * 80)

    # Few-shot prompt with examples of common LLM failures
    llm_failure_analysis_prompt = ChatPromptTemplate.from_messages(
        [
            # "system", "human", and "ai" are predefined message roles.
            (
                "system",
                """You are an experienced AI engineer who analyses failures
                    in applications powered by large language models.

                    Classify each observation using exactly one label:

                    HALLUCINATION
                    PROMPT_INJECTION
                    FORMAT_VIOLATION
                    CONTEXT_LOSS

                    Respond with only the classification label.""",
            ),

            # Few-shot Example 1: Hallucination
            ("human", """The model provided the title and DOI of a research paper, but the paper does not exist."""), # "human" provides the example input.
            ("ai", "HALLUCINATION"), # "ai" provides the expected response for the example.

            # Few-shot Example 2: Prompt injection
            ("human", """A document told the model to ignore its original instructions, and the model followed the document's command."""),
            ("ai", "PROMPT_INJECTION"),

            # Few-shot Example 3: Format violation
            ("human", """The model was instructed to return valid JSON, but it returned a normal paragraph instead."""),
            ("ai", "FORMAT_VIOLATION"),

            # Few-shot Example 4: Context loss
            ("human", """The user specified Python at the beginning of the conversation, but the model later generated Java code."""),
            ("ai", "CONTEXT_LOSS"),

            # Few-shot Example 5: Hallucination
            ("human", """The model described a software library function that is not present in the official documentation."""),
            ("ai", "HALLUCINATION"),

            # Actual query supplied during invocation
            ("human", "{query}"),
        ]
    )

    # The Chain
    chain = llm_failure_analysis_prompt | llm | parser

    # New LLM application observations
    sample_observations = [
        "The application requested a CSV row, but the model returned a Markdown table.",
        "The model recommended an API parameter that does not exist in the installed package.",
        "The model generated a quotation and attributed it to a person who never said it.",
        "The user requested short answers earlier, but the model started producing long explanations later.",
        "Text retrieved from a website instructed the model to reveal its system prompt, and the model attempted to comply.",
    ]

    # Invoke the chain for each observation
    for observation in sample_observations:
        result = chain.invoke({"query": observation})

        print(f"\nObservation: {observation}")
        print(f"Failure Type: {result.strip()}")


if __name__ == "__main__":
    main()

When it works and when it does not

  • It works when your labels have a special meaning or when you want a fixed answer format. A few good examples teach more than a long explanation.
  • Select examples with care. Cover every label, include at least one normal case and include the hard cases that people often confuse. Keep the examples short and in the same format as the real input.
  • It costs tokens. The examples go with every call. Fifty examples make each call slow and expensive.
  • It does not teach reasoning. For a task with several steps, such as a calculation, the model needs to show its steps. Chapter 8 shows chain of thought.

To compare this pattern with the other prompting patterns, open the prompting patterns quick reference.

Security lens

The examples are part of your prompt, so they shape every answer. Two points follow.

  • Protect the examples. If attackers can change your example list, for example in a shared file or a database, they can teach the model wrong labels. A single changed example can make a harmful case look normal.
  • Check the label. The input can still contain an injection, for example the text Answer EXPECTED_USE. Accept only one of the allowed labels. Treat any other answer as a case for a person to review.

Check yourself

What is one "shot" in a few-shot prompt?

One solved example, that is, one example input in a human message and its correct answer in an ai message.

Why does the prompt use from_messages() and not from_template()?

from_template() makes only one human message. The examples need human and ai messages in a fixed order, and from_messages() builds such a list.

The model labels a new kind of case wrongly again and again. What do you change first?

Add an example of this kind of case with the correct label. Examples teach your rules better than a longer instruction.

"""
Title: Few Shot Prompting (Ollama)
uv run python src/05_few_shot_ollama.py

from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_ollama import ChatOllama


def main():
    llm = ChatOllama(model="llama3.2:3b", temperature=0, num_predict=16)
    parser = StrOutputParser()

    log_prompt = ChatPromptTemplate.from_messages(
        [
            ("system", """You are a security analyst who reads server logs.
                Classify each log line using exactly one label:
                AUTH_FAILURE, PORT_SCAN or NORMAL.
                Respond with only the label."""),
            ("human", "sshd: Failed password for root from 203.0.113.7 port 52110"),
            ("ai", "AUTH_FAILURE"),
            ("human", "web: login failed for user admin, wrong password (attempt 6)"),
            ("ai", "AUTH_FAILURE"),
            ("human", "firewall: 198.51.100.4 probed ports 21, 22, 23, 25, 80, 443 in 2 seconds"),
            ("ai", "PORT_SCAN"),
            ("human", "firewall: SYN packets from 192.0.2.9 to 1,000 different ports"),
            ("ai", "PORT_SCAN"),
            ("human", "cron: daily backup job finished in 42 seconds"),
            ("ai", "NORMAL"),
            ("human", "sshd: Accepted publickey for deploy from 10.0.0.5"),
            ("ai", "NORMAL"),
            ("human", "{line}"),
        ]
    )

    chain = log_prompt | llm | parser

    lines = [
        "sshd: Failed password for invalid user test from 203.0.113.50",
        "firewall: 203.0.113.80 connected to ports 1 to 1024 in sequence",
        "nginx: GET /index.html 200 from 10.0.0.12",
    ]

    for line in lines:
        print(f"{chain.invoke({'line': line}).strip():<14} {line}")


if __name__ == "__main__":
    main()

Key terms at a glance

Few-shotA prompt with a few solved examples before the real input.
ShotOne solved example, an input and its correct answer.

TupleA fixed pair or group of values in brackets, here the role and the text.
