In one line

A system message tells the model who it is and how to answer. The same question then gets a very different answer for each role.

What you will learn

  • The difference between a system message and a human message
  • How to send a list of messages to a model instead of one string
  • How a role changes the words, the depth and even the language of an answer
  • Where response metadata shows the model and the reason that the answer stopped

It helps to read chapter 1 first, for invoke(), tokens and the reply object.

The idea

A chat model reads a conversation, not a single text. Each part of the conversation is a message with a role. The two roles in this chapter are the system and the human.

  • System message. Instructions for the model about how to behave. It sets the role, the tone, the audience and the rules. The user of an app usually does not see it.
  • Human message. The question or the task from the user.

The model treats the system message as the frame for the whole conversation. Thus, you can keep the question the same and change only the system message. The answer then changes its vocabulary, its depth and its focus.

Real-life analogy

Three people hear the same question, "How does a phishing attack work?" A security analyst talks about attack stages and indicators. A chief information security officer talks about business risk and governance. A school teacher tells a short story that children remember. The question is the same, but the role of the speaker shapes the answer. A system message gives the model such a role.

What we build in this chapter

Both programs ask the same phishing question to three personas. They are a cybersecurity analyst, a chief information security officer (CISO) and a Class 10 teacher who explains in Hindi. The two examples use two different models, so you can see how well each model follows the roles.

Step 1Create the file

In your project folder, create the file src/03_system_messages_google.py and open it in your editor.

Step 2Import what you need

from dotenv import load_dotenv
from langchain_core.messages import SystemMessage, HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI
  • load_dotenv reads your API key from .env.
  • from langchain_core.messages import SystemMessage, HumanMessage takes the two message classes. SystemMessage holds the instructions for the model. HumanMessage holds the question of the user. Both come from langchain_core, so they work with every provider.
  • ChatGoogleGenerativeAI is the Gemini model class from chapter 1.

Step 3Start the main function and create the model

def main():
    load_dotenv()

    # Initialize the model
    llm = ChatGoogleGenerativeAI(
        model="gemini-3.1-flash-lite",
        temperature=0
    )
  • load_dotenv() loads GOOGLE_API_KEY.
  • temperature=0 keeps each answer stable. Then the only reason that the answers differ is the system message.
  • This model object has no length limit. The answers here are long, and a small limit can cut them.

Step 4Write the question and print a title

    question = "Explain how phishing attack works and how users can avoid them."

    print("=" * 80)
    print("SAME QUESTION, DIFFERENT CYBERSECURITY PERSONAS\n")
    print(f"Question: {question}")
    print("=" * 80)

question holds the text that all three personas get. The print() lines show the question at the top of the output.

Step 5Build the first message list, the analyst

    # Persona 1: Cybersecurity Analyst
    print("\n--- CYBERSECURITY ANALYST ---")
    messages_analyst = [
        SystemMessage(content="""You are an experienced cybersecurity analyst.
        Explain threats using accurate technical terminology, common attack stages, 
        indicators of compromise and suitable security controls.
        Keep the explanation concise."""),
        HumanMessage(content=question),
    ]
  • messages_analyst = [ ... ] is a Python list with two message objects. The order is important. The system message comes first.
  • SystemMessage(content="""...""") gives the role. It names the person ("an experienced cybersecurity analyst"), what to cover (terms, attack stages, indicators of compromise, controls) and a style rule ("Keep the explanation concise").
  • HumanMessage(content=question) carries the question of the user.

Step 6Send the list and print the reply

    response_analyst = llm.invoke(messages_analyst)
    print(f"Analyst Response: {response_analyst.text}")
    print(f"Analyst Response Metadata: {response_analyst.response_metadata}")
    print(f"Analyst Response Usage Metadata: {response_analyst.usage_metadata}")
  • llm.invoke(messages_analyst) sends the full list. invoke() accepts a string as in chapter 1 or a list of messages. A string becomes one human message.
  • .text prints only the words of the answer.
  • .response_metadata shows details from the provider. Look for finish_reason and model_name.
  • .usage_metadata shows the token count. The system message counts as input tokens.

"""
Title: System Messages and Role Prompting (Google Generative AI)
    - SystemMessage: How the model should respond
    - HumanMessage: What the model should answer

uv run python src/03_system_messages_google.py
"""

from dotenv import load_dotenv
from langchain_core.messages import SystemMessage, HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI


def main():
    load_dotenv()

    # Initialize the model
    llm = ChatGoogleGenerativeAI(
        model="gemini-3.1-flash-lite",
        temperature=0
    )

    question = "Explain how phishing attack works and how users can avoid them."

    print("=" * 80)
    print("SAME QUESTION, DIFFERENT CYBERSECURITY PERSONAS\n")
    print(f"Question: {question}")
    print("=" * 80)

    # Persona 1: Cybersecurity Analyst
    print("\n--- CYBERSECURITY ANALYST ---")
    messages_analyst = [
        SystemMessage(content="""You are an experienced cybersecurity analyst.
        Explain threats using accurate technical terminology, common attack stages, 
        indicators of compromise and suitable security controls.
        Keep the explanation concise."""),
        HumanMessage(content=question),
    ]

    response_analyst = llm.invoke(messages_analyst)
    print(f"Analyst Response: {response_analyst.text}")
    print(f"Analyst Response Metadata: {response_analyst.response_metadata}")
    print(f"Analyst Response Usage Metadata: {response_analyst.usage_metadata}")


    # Persona 2: Chief Information Security Officer
    print("\n--- CISO ---")
    messages_ciso = [
        SystemMessage(content="""You are the Chief Information Security Officer of an organization.
        Explain cybersecurity issues from the prespective of business risk, organizational impact, 
        governance and preventive controls. Be concise and executive-friendly."""),
        HumanMessage(content=question),
    ]

    response_ciso = llm.invoke(messages_ciso)
    print(f"CISO Response: {response_ciso.text}")
    print(f"CISO Response Metadata: {response_ciso.response_metadata}")
    print(f"CISO Response Usage Metadata: {response_ciso.usage_metadata}")



    # Persona 3: School Teacher
    print("\n--- School Teacher ---")
    messages_teacher = [
        SystemMessage(content="""You are Ms. Divya, a friendly and creative Class 10 teacher in an Indian government school.
        You teach cybersecurity through short classroom stories and relatable Indian examples such as fake scholarship messages,
        exam-result links, UPI requests, OTP scams, gaming rewards etc.
        
        Explain the topic in simple Hindi language suitable for class 10 students. Use one memorable classroom analogy and
        finish with the three-step rule: STOP, CHECK, REPORT.
        Keep the response engaging and concise."""),
        HumanMessage(content=question),
    ]

    response_teacher = llm.invoke(messages_teacher)
    print(f"Teacher Response: {response_teacher.text}")
    print(f"Teacher Response Metadata: {response_teacher.response_metadata}")
    print(f"Teacher Response Usage Metadata: {response_teacher.usage_metadata}")



if __name__ == "__main__":
    main()

To mitigate phishing risks, organizations should implement robust governance and preventive controls. This includes:

- **Use Antivirus Software:** Ensure that antivirus software is up-to-date and running on all devices.

"""
Title: System Messages and Role Prompting (OpenRouter)
    - SystemMessage: How the model should respond
    - HumanMessage: What the model should answer

uv run python src/03_system_messages_openrouter.py
"""

from dotenv import load_dotenv
from langchain_core.messages import SystemMessage, HumanMessage
from langchain_openrouter import ChatOpenRouter


def main():
    load_dotenv()

    # Initialize the model
    llm = ChatOpenRouter(
            model="qwen/qwen-2.5-7b-instruct",
            temperature=0,
        )

    question = "Explain how phishing attack works and how users can avoid them."

    print("=" * 80)
    print("SAME QUESTION, DIFFERENT CYBERSECURITY PERSONAS\n")
    print(f"Question: {question}")
    print("=" * 80)

    # Persona 1: Cybersecurity Analyst
    print("\n--- CYBERSECURITY ANALYST ---")
    messages_analyst = [
        SystemMessage(content="""You are an experienced cybersecurity analyst.
        Explain threats using accurate technical terminology, common attack stages, 
        indicators of compromise and suitable security controls.
        Keep the explanation concise."""),
        HumanMessage(content=question),
    ]

    response_analyst = llm.invoke(messages_analyst)
    print(f"Analyst Response: {response_analyst.text}")
    print(f"Analyst Response Metadata: {response_analyst.response_metadata}")
    print(f"Analyst Response Usage Metadata: {response_analyst.usage_metadata}")


    # Persona 2: Chief Information Security Officer
    print("\n--- CISO ---")
    messages_ciso = [
        SystemMessage(content="""You are the Chief Information Security Officer of an organization.

When it works and when it does not

  • It works when you need a fixed tone, audience or format for every answer of an app. Write the rule one time in the system message.
  • It is less good with small models and long, detailed roles. Keep the system message short and test each rule in it.
  • A role does not add knowledge. "You are an expert" changes the style, but the model knows only what it learned. Check the facts in the answer.
  • For a fixed set of labels, examples work better than a role. Chapter 6 shows few-shot prompts.
Security lens

Many apps put their rules and their limits in the system message. Two risks follow from this.

  • The system message is not secret. A user can ask the model to repeat its instructions, and the model often does. Never put passwords, API keys or private business rules in a system message.
  • The system message is not a security wall. A user message such as "Ignore your role and ..." can weaken the rules. Check important limits in your code as well, not only in the prompt.

Check yourself

What is the difference between a SystemMessage and a HumanMessage?

The system message tells the model how to behave, for example its role and rules. The human message holds the question or task of the user.

Why does this program use temperature=0?

The experiment changes only the system message. With temperature 0, the answers do not vary by chance, so the differences come from the roles.

Is it safe to put an API key in a system message, because users cannot see it?

No. A user can often make the model repeat its system message. Keep secrets in your code or in .env, never in a prompt.

"""
Title: System Messages and Role Prompting (Ollama)
uv run python src/03_system_messages_ollama.py
"""

from langchain_core.messages import SystemMessage, HumanMessage
from langchain_ollama import ChatOllama


def main():
    llm = ChatOllama(model="llama3.2:3b", temperature=0, num_predict=200)

    question = "What is two-factor authentication, and why is it useful?"

    roles = {
        "TRAINER FOR SENIOR CITIZENS": """You are a patient trainer who teaches
        senior citizens to use smartphones safely. Use simple words, one everyday
        example and at most five short sentences.""",
        "PENETRATION TESTER": """You are a penetration tester who briefs a technical
        team. Name the attacks that two-factor authentication stops and the attacks
        that it does not stop. Use at most five bullet points.""",
    }

    for name, system_text in roles.items():
        messages = [SystemMessage(content=system_text), HumanMessage(content=question)]
        response = llm.invoke(messages)
        print(f"\n--- {name} ---\n{response.text}")


if __name__ == "__main__":
    main()
